# 变更和恢复

- 原 v2 的代码、数据、训练与分析规则一律不由本包改变。
- 本包 freeze 后，修改代码、配置、依赖版本或源身份均拒绝续跑。新版本使用新输出根，旧结果保留。
- 当前运行没有自重启服务；每状态是有限子进程，timeout 会保留 INCONCLUSIVE。异常断电留下 ACTIVE.lock 时先检查所有本包 PID。
- 本包不自动重试已提交的 EXECUTION_ERROR / TIMEOUT / NUMERIC_UNRESOLVED；先诊断。确认恢复是同版本工程问题时，用单独的新执行根保存恢复结果和旧结果链接，不删失败证据。
- 输出目录不能是输入目录的子目录/父目录，也不能放进包内；路径穿越/符号链接越界被拒绝。
- 单 GPU 守卫不能防止其他人随后手动启动进程。ApproveCompute 表示本地执行者已取得该窗口；脚本同时检查进程并持有自己的唯一锁。
- Windows WDDM 可能不完整暴露 GPU 进程/显存：查询失败不强行继续，要求本机核验，不以第三方 token/API绕过。
- 没有 GitHub 写入功能。需要回传结果时仅导出报告、CSV、结果收据与源码 diff；明确排除 local_inputs、数据、权重、凭证和不必要的私人路径。
