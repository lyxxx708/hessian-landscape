# GENESIS NEXT v1：结构—作用—成本的可证伪配对实验

版本：1.0；设计日期：2026-11-05。
依据：2026-11-04 20:11（UTC+8）固定审计快照；Git commit `629032110fa51affc7f4e96cdb75f0c40070a9fe`。
**这是新提出的补充实验设计，不是此前已经预注册的 v2 协议，也不声称实验已经完成。**

## 1. 本轮要裁决什么

主问题不是“逆矩阵有没有非对角元素”，而是：**可见的跨层逆曲率结构，哪些真正影响当前梯度的更新，获得这些收益需要多少计算？**

保留两个有竞争关系的解释，而不是只寻找支持原想法的结果：

- H1：原始逆曲率非局域能量中，大量成分来自与梯度弱耦合的（近）零空间；因此矩阵结构复杂度不可靠地代表优化收益或求解成本。
- H2：特定非线性状态的跨层耦合确实决定 Block-GGN 损失，且短 CG 不能廉价补回；这才有进一步算法研究的空间。

可以支持 H1，也可以支持 H2；也可能不同模型/状态各自成立。任何“强非局域结构”“CG 很快”“FP64 成功”都不能单独宣布新优化器有效。

已知 DLN 文献已经讨论复杂 Fisher 结构与简单自然梯度更新的关系。DLN 上复现这个方向不足以主张首创。见 SOURCES.md 的 Bernacchia 等（NeurIPS 2018）。本轮只作机制识别和可行性判断，不保证论文发表。

## 2. 与当前实验的关系

原 v2 的 130 条 S1 和 96 条 S2 继续遵守原协议，原始标签、测量、predictor、队列和门禁均不得修改。本包既不替换 v2.1，也不切换旧 pipeline。没有任何代码调用 v2 的 `measure_job`、`adjudicate`、`report`、`run_stage` 或训练入口。

本轮仅复用 **S1** checkpoint。S1 已被观察过，全部新增分析标记 `POSTHOC_S1_EXPLORATORY_NOT_CONFIRMATION`。既有 S2 只能确认原来冻结的端点；不得拿它调新指标、新求解器或新阈值。新主张要做确认，需要另行冻结的新独立样本，或经明确暴露审计证明仍未见的预留样本。见 CONFIRMATION_EXTENSION.md。

默认先运行 E0，不需要 GPU、训练数据或模型权重。不以任何审计为旧 S1/S2 的新阻塞门禁。真实 checkpoint 实验需要原 worker 已经通过既有安全流程退出；本包不会替用户暂停/终止它。资源窗口可以放在旧实验结束之后，也可以由本地执行者按照已有权限安排有限的合作式暂停；暂停决策不由本脚本自动作出。

## 4. E0：立即复算现有证据，不做新神经网络计算

**输入**：本地审计包中的 predictor-feature 表、610 行 FP32/FP64 audit 表、机制记录和 manifest。

**输出**：
- 完整 checkpoint 1/2/3 的 seed 中位数及 γ=.01/.1 配对差值。
- 原始 matched-CG、short-CG 相对于原 FP32 oracle 的收益比。
- audit 的逐行误差与独立状态/seed 的分母说明。
- 对机制记录按 `(setting, seed, checkpoint)` 去重；零空间贡献用 **范数平方**，不能用范数之和冒充能量分解。

这一步应能检查此前 40/40 配对趋势、305 条收益比和 3 个 distinct false-valid 案例。但程序不把这些数字写成测试通过条件：输入版本变化时应报告真实结果，而不是追逐旧数字。若哈希不一致，不分析。

E0 不训练 predictor，不执行正式 adjudication，不因原报告尚未生成而拒绝描述已有数据。

## 5. Q0：每个架构的生产资格先测，不把 CPU 成功当 CUDA 成功

每个 family 选固定的第一个入选 setting、seed index 1、checkpoint 3：DLN d4、MLP d6、ResNet20、Transformer d4。它们是 80 状态面板的子集，不额外乘样本数。先运行每次最多一个状态。每族通过后可处理该族其他状态；未有成熟 checkpoint 的族等待，不临时训练替代案例。

执行设备写入新锁；CPU/CUDA 不共用资格收据或输出根。全部采用本轮的 FP64 完整算子；明确禁用 TF32；固定 OMP/OpenBLAS/MKL/PyTorch 线程数为 2。真实 CUDA 测量记录 allocated/reserved VRAM、GGNv、wall time、参考计算与在线候选成本，内存目标 9.5 GiB。9.5 GiB 是本轮运行目标，不是已测可行性结论。

每状态子进程上限 3,600 秒；超时只终止本包自己的子进程，记 `TIMEOUT_INCONCLUSIVE`，不把它算成科学负例。每次调用最多 4 状态，默认 1；没有隐含的持续 CPU 大任务或系统服务。若上限不足，保持当前结果；要改上限需新 lock/root，不能改已有 freeze。

参考解真实相对残差 ≤1e-8；主/独立算子随机向量差异 ≤1e-6；主/独立梯度差异 ≤1e-6；主/参考方向差异 ≤1e-5；小模型 δ 与稠密参考绝对差 ≤1e-5。以上是本次提出的数值资格值，需由 Q0 检验可行性，不是从 v2 协议继承的确认性阈值。

## 6. E1：在同一 checkpoint 比较结构信息与求解成本

设 `Q=G+λI`，`λ=γ max(spectral_scale_v2, damping_floor)`。用原 v2 记录的绝对尺度，避免新的谱估计改变问题。

**主参考输入必须是原 v2 FP32 batch 的数学值，精确升到 FP64。** DLN 源数据本来是 FP64；直接以 FP64 重建会使用未量化的 x/y，在近收敛状态可能改变问题。原生 FP64 数据只用于单列的输入量化对照，不混入主精度结论。

每个条件比较：
1. 高精度 full-GGN 方向；仅作科学参考，不免费提供给在线策略。
2. 精确 block-GGN 方向，加最佳标量二次型校正。
3. 本包独立的无预条件 CG（无周期重启，末端检查真实残差，不冒充原 v2.1 V3 实现）：固定 1、2、4、8、16、32、64 步。
4. Matvec-matched CG：预算为本轮 block 求解实际 GGNv 加一次 `Qb`。这与 v2 的旧预算不同，结果单独命名，不能串接旧曲线。

记录 `F(d)=-gᵀd−½dᵀQd`、`δ=1−F_B/F*`、绝对差 `F*−F_B`、`F*/loss`、方向/残差、固定迭代收益曲线、首次被测试到达到 99% 收益的预算。稀疏预算网格只能给“首次采样交点”，不能声称精确最小 K99；未达到则右删失，不补零。

在同一训练 batch 上使用原固定标量步长集合，并只用训练损失选择步长；验证 batch 只评价，不调参。所有方法记录同样的候选评估次数，区分“二次型收益”与“真实单步 loss 改善”。接近舍入噪声的 loss 差标明不可稳定解释。

**成本**：记录每个候选自身 matvec/实际 solve wall time/line-search wall time；full oracle、独立参考和诊断耗时单列。这里的固定顺序 timing 是工程成本诊断，不能作为随机化 optimizer speedup benchmark。不得将“同 GGNv”称为“同 wall-clock”。

**可证伪点**：若非线性模型中的短 CG 在原有效成本内持续补不回 Block 的损失，H1 的普遍版本不成立；若短 CG 总能补回，也不能靠美观的矩阵图继续声称必须构建完整逆矩阵。

## 7. E2：零空间、有效方向与 Hessian 的谱尺度

嵌入 E1，不另开训练网格。仅对参数 ≤2,048 且输出元素 ≤4,096 的状态构造独立稠密 `J/W/G/H`；大模型明确 `NOT_APPLICABLE_DENSE_LIMIT`，禁止分配百万参数平方矩阵。

对 1e-10、1e-8、1e-6 三档相对 rank 阈值同时报告：
- rank/nullity、near-null 梯度投影 `||P0 g||/||g||`；这是数值 near-null，不是真实精确秩证书。
- `||(G+λI)^−1_near-null||²_F / ||(G+λI)^−1||²_F`。
- 整体 inverse、near-null 部分和 active 部分的跨块能量。
- 梯度条件化谱收益权重 `w_i ∝ (v_iᵀg)²/(μ_i+λ)`；达到 99% 权重的方向数与有效方向数。它们是候选描述量，不等价于 CG 迭代次数定理。
- `||H−G||_F/||H||_F`、负特征值绝对大小、负谱质量、阈值附近模糊谱数量。**大量很小的负特征值，不等于重要鞍点；整体接近也不保证逆问题稳定。**

MSE 下 `g=Jᵀr` 位于 Jacobian 行空间，是已知代数事实，不可包装成发现。研究贡献若有，应来自哪些结构/任务/状态使原始矩阵描述量误判优化作用，以及这一误判可被什么量预测。

## 8. E3：坐标变换对照，不把 gauge 冗余当新物理

复用 DLN 稠密结果，仅固定 seed index 1、checkpoint 3，4 个 setting；相邻两层 `W0'=sW0, W1'=W1/s`，s∈{.5,2,10}，三档 γ，共 36 个配对条件。

同时比较：
- 原坐标的 `G+λI`。
- 新坐标仍用 `G'+λI`：它实际改变了正则化度量。
- 协变变换的 `G'+λT^−T T^−1`，其中 `θ'=Tθ`。

检查真实模型输出、梯度与 GGNv 的协变关系，再比较映回原坐标的 full direction、Block/Full δ 和逆矩阵能量。后两项协变等式应恢复是**负对照/正确性测试**，不是预期新发现。若协变对照不通过，先判断数值/接口问题，不得解释为规范对称破缺。

不假定 ResNet、Transformer 具有同样的缩放对称性；不将 DLN 变换生搬硬套。

## 9. E4：解释 false-valid，而不预先认定全部来自 FP32 运算

嵌入每个 E1 状态，区分：
1. 同设备、同量化输入值的 FP32 与 FP64 梯度/三个固定 GGNv 探针差异；
2. DLN 原生 FP64 x/y 与 FP32 输入值升精度后的差异（输入量化）；
3. 独立稠密/反向参考与主算子的差异；
4. 原 v2 δ 与本轮主参考 δ 的差异（附原收据 SHA）。

允许推翻以前“全部是 FP32 梯度运算错误”的归因。不能仅凭 `|g|<阈值` 丢弃数据；零梯度比值不可评估另列，但不计作无效科学假设。绝对效应与相对误差同时报告。

## 10. 分析与继续/停止规则

统计单位为 training seed；同 seed 的 checkpoint 1、3 先取中位数，γ 分开，每个 setting 分开。合格种子少于 4 时不报告置信区间，只给数值与缺口。95% percentile bootstrap 是小样本探索性区间，不是新的确认性检验。不根据本轮结果改变旧 v2 的 S1 predictor/S2 seed。

本轮输出三类判断，而非一个“PASS”总按钮：
- **数值可解释**：各条件有可核查参考，不通过即不使用数值端点，仍计入分母。
- **机制值得继续**：原始结构量与任务相关量存在有重复证据的分离，并能在相应 family 重现；若只发生在一个 seed，就报告局部现象。
- **算法值得投入**：非线性状态的差距在公平候选成本下不能被短 CG 轻易消除，且真实单步验证损失存在可解析改善。该条件只是进入新优化器实验的筛选，不是最终加速证明。

若 matched CG 仍追上参考，论文方向转为机制/负结果，不通过调弱 baseline 制造优势。若 FP64 准确但设备成本不可接受，记录可行性 NO-GO，不自动降低精度或搬到云端。若源数据哈希不同、参考不一致或显存不足，保持原数据不动并留明确失败收据。

## 11. 开封即用的交付边界

本包已经实现：E0、80 状态计划/冻结、只读 checkpoint 适配器、每族 Q0、E1/E2/E3/E4 数值测量、超时隔离、结果摘要、测试和合成演示。

不自动实现/启动：新的训练、正式 S2 的新端点分析、长程 optimizer benchmark、旧 worker 暂停/恢复、GitHub 推送或持久化监控。它们不是完成本轮机制诊断的前置条件。

当前制作环境只有 Linux CPU，无法访问 E: 和真实 GPU；验收文件诚实区分已通过的数学/接口/文件流程测试与待本机验证的 Windows/CUDA/真实 checkpoint。测试成功不是科学假设成立。
