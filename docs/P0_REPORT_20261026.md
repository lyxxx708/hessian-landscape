- Batch: N=32 standard-Gaussian input rows from seeded RNG; teacher target `X` for `initial`, exact model prediction at the same W for `zero_residual`.
- Loss: `0.5 * mean((prediction - target)**2)` normalized by `M=N*10=320`, not `0.5/N`.
- Curvature: exact analytic H=J^T J/M + sum_a r_a Hessian(r_a)/M, and GGN=J^T J/M, explicit 1,200x1,200 float64, lambda=0.001.
- Matrix inverse: full symmetric `numpy.linalg.eigh` on exact H; `(H+lambda*I)^-1` via eigen-decomposition, residual checked.
- RMS: layer-block size=100, count(k)=12 if k=0 else 2(12-k); ordered pairs include both triangles.
- Seeds: 20261026, 20261027, 20261028, identical seeds for both target conditions; 3 shared-seed clusters, *not* an inferential replication study.
- Environment: NumPy 2.3.5, Python 3.13.5, requested OpenBLAS threads 2; raw environment recorded in each JSON.

## New analytic control: exact flat-distance plateau under scaled-orthogonal weights

For a fixed zero-residual DLN with identical layer scales and orthogonal Q_i, each layer Jacobian block J_i has the same output-space Gram: J_i J_i^T=J_0 J_0^T (up to floating noise), although their parameter bases differ. Thus J_i=J_0 O_i for orthogonal O_i acting on the d^2 layer parameters. In particular J J^T=L J_0 J_0^T.

By Woodbury:

`R_ij = delta_ij lambda^-1 I - lambda^-1 J_i^T (J J^T + M lambda I)^-1 J_j`.

Substituting the O_i yields `R_ij=O_i^T (delta_ij lambda^-1 I - lambda^-1 C) O_j` for a common C. Consequently every off-diagonal layer block has exactly the same Frobenius norm, and all diagonal blocks share a norm. Hence all normalized distance bins k>=1 are *exactly flat*, without an architecture-specific phase transition.

The observed values 0.090502–0.090571 are close to the scalar rank-one toy limit `1/(L-1)=0.090909`, but the exact finite-lambda multidimensional numbers depend on data covariance and spectrum. They are **not mathematically identical to 1/(L-1)**.

For an exactly flat c, the total offdiagonal energy identity is

`mass_off = (L-1) c^2 / [1+(L-1)c^2]`.

At L=12 and c<=0.12, max mass=**13.6740%**, not 39%. With c around 0.0905 the formula yields approx 8.27%, consistent with all independent runs. Historical 39% and <=0.12 cannot both hold for the same 12x12 equal-size block metric and same run. **Original result is not resolved by these different runs.**
