# 实施后代码自审与发布边界

审查方式：作者分模块静态复核 + 故障注入 + 独立算法路径的数值重算。当前工具未提供独立 subagent；不将该自审称为第二位独立 reviewer 的批准。无 remote merge。

## 已定位并修复的高影响问题

- G0异常可能保留旧绿灯：失败路径覆盖为 `G0_FAILED`，旧收据归档；测试注入导数故障确认冻结不得继续。
- 统计标准不能把checkpoint/λ当seed：U按seed聚合、部分合取检验、Holm；P按seed-group划分与重采样。
- 求解残差小不代表前向精确：Full/Block十倍容差稳定性；结构逐bin误差界，不再用被巨大对角项淹没的平均误差。
- 软件库改变原锁仍可继续：runtime ABI纳入G0/lock，版本变化必须新协议。
- 原始小CG与成本匹配CG混淆：两个独立receipt，计入真实matvec与true-residual刷新。
- QA完成后台账改变：报告重新核对jobs_digest和冻结状态，拒绝复用过期QA。
- 报告重生成旧hash：最后写入report_receipt之后再计算manifest，故障测试覆盖二次生成。
- S3只对AdamW证明提升：改为所有预注册基线成对、保守interval-censor时间界、相等wall预算质量门禁、Holm；缺失/右截尾不能丢弃后宣称速度提升。
- CPU入口误把`--help`当路径：改为真正argparse，测试确认help不会启动训练；仅终止并清理该测试生成的确切子进程/目录。
- 包覆盖已有科研目录：增量安装先检查全量冲突/路径逃逸，再复制；不覆盖历史AGENTS/README。

## 尚需本机验收，绝不预先宣称PASS

1. RTX 4070 Ti驱动/wheel实际兼容与四族CUDA算子、真实microbatch显存、温度、硬盘估算。
2. Windows 原生 PowerShell/文件锁/断电重启：当前仅静态入口合同检查与可移植恢复测试。新增CI可在Windows CPU runner执行解析/测试，但本次未运行远程CI。
3. 公开数据下载与许可接受、真实完整训练；本环境无这些数据，不用合成结果替代。
4. 全规模S3 K-FAC/GS/CG吞吐与公平性，均需真实本机记录；参考单元测试只是算法/工程资格。
5. 旧仓库完整回归：容器不能clone，未取得全部旧代码，不声称旧tests运行。安全overlay之后由Codex运行旧单元测试和新增pytest。

## 明确不做的非必要/可选工作

- 不迁移C盘现有文件，不更改pagefile、用户profile、驱动或全局TEMP，不挂开机常驻服务。
- 不承诺有限深度定理/新颖性/真实优化器加速，不把独立代码路径测试称人类审稿。
- 未认证的可选高级GPU加速不加入默认科学oracle，避免偏差/成本被隐藏。

**判断：**源码可进入用户机器的软件/环境/G0验收和独立代码评审；尚不具备“CUDA全研究已通过”或“可直接合并main”的证据。
