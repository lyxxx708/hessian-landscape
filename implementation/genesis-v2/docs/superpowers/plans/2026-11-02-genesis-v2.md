# GENESIS v2 executable Implementation Plan

> For agentic workers: execute this approved blueprint inline, using TDD and a separate final review.

**Goal:** Deliver executable, evidence-preserving S/M/U/P research software following the attached v2 blueprint, not synthetic claims of a GPU experiment.
**Architecture:** Immutable mathematical contracts; deterministic training/measurement workers; read-only independent audit/report plane.
**Tech Stack:** Python 3.11+, PyTorch torch.func, NumPy/SciPy, SQLite, safetensors, YAML, PowerShell.
**Spec:** docs/spec/GENESIS_v2_Blueprint_Design_Only.md

## Global Constraints
- Production CUDA required; CPU smoke never counts as GPU G0 or science.
- E: only bulk Windows storage; no C: overflow; process-local cache configuration.
- 130 S1 and 96 S2 independent trajectories; A/B all states; predeclared C-base/C-deep.
- Same snapshot/batch/objective/parameter layout; distinct alpha_Q and alpha_task.
- Correct MSE/CE GGN; exact-H never silently fed to SPD CG.
- No LLM calls inside execution loops; no paid services; no historical evidence promotion.
- No main merge or raw-data publication.

## Review Focus
Corrupted/tampered locks and artifacts; shared parameters; CE ignored targets and zero logits shifts; crash recovery with live PID; invalid seeds mistaken for negative evidence.

## Tasks
1. Contracts, plan generator, hashing/storage and adversarial tests.
2. Four model families, immutable operators, independent dense oracle and numerical tests.
3. CG/block/dual solvers, utility, sketches, mechanisms and controls.
4. Datasets, checkpoint-safe training and exact resume tests.
5. Queue/state/lock/G0/freeze/measurement runner and system tests.
6. Cluster statistics, predictor, conditional S3, audit/report and CLI.
7. E-drive Windows launcher, offline smoke, full tests, packaging and review.

Each task: tests RED -> implementation -> targeted GREEN -> complete suite -> commit and ledger.
